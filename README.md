# تطبيق تحفيظ القرآن — Tahfeez App

نسخة Test أولية لنظام إدارة حلقات تحفيظ القرآن.

## الحالة
- واجهة عربية RTL ومتجاوبة.
- أدوار: Super Admin / إدارة / معلم.
- إدارة المعلمين CRUD محليًا.
- إدارة الطلاب والحلقات.
- الحضور والتسميع والحفظ والمراجعة.
- قوالب رسائل WhatsApp وفتح المحادثة برسالة جاهزة.
- حفظ بيانات الاختبار في LocalStorage.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشر المستودع عبر GitHub Pages لأي اختبار واجهة.

## المرحلة التالية
ربط Backend وقاعدة بيانات حقيقية، مصادقة حقيقية، وصلة WhatsApp Business Cloud API، وسجل إرسال ورسائل وقوالب مع صلاحيات على مستوى الخادم.

> لا يتم وضع أي Access Token أو Secret داخل الواجهة الأمامية. مفاتيح WhatsApp يجب أن تبقى في الخادم/متغيرات البيئة.
